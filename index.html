Guia de Apoio ao Visual Studio Code

Bem-vindo à página de dicas, atalhos e boas práticas para otimizar o seu uso diário do VS Code.

Atalhos Úteis

  • Ctrl + Shift + P — Abre a Paleta de Comandos
  • Ctrl + P — Busca rápida de arquivos
  • Ctrl + ` — Abre o terminal integrado
  • Alt + Shift + F — Formata o código do arquivo atual
  • Ctrl + / — Comenta ou descomenta a linha selecionada

Extensões Recomendadas

  • Prettier: Formatação automática de código.
  • GitLens: Supercharged para o controle de versão Git.
  • Live Server: Servidor local para testes em tempo real de páginas HTML.

Dica Prática

Mantenha sempre os arquivos organizados em pastas bem definidas e utilize o painel lateral de controle de versão (Source Control) para acompanhar o que foi modificado antes de realizar os commits.
